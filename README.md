# 스튜디오(PP_01_01_Studio)
이 프로젝트는 Behind The Scene 시스템의 ‘촬영’ 단계를 담당하는 클라이언트 프로그램입니다.</br>
웹캠으로 얼굴을 촬영하고, 해당 이미지를 서버로 전송하여 하나의 체험 세션을 시작합니다.</br>
</br>
촬영이 완료되면 서버로부터 **세션 코드(고유 비밀번호)**를 발급받아 체험자가 다음 단계인 Editor로 이동할 수 있도록 합니다.</br>
</br>
*데모 버전에서는 실제 웹캠 촬영 대신 샘플 이미지를 사용하여 촬영 및 세션 생성 흐름만 재현하도록 구성되어 있습니다.
</br>

### 주요 기능
├─ 웹캠을 이용한 얼굴 촬영</br>
├─ 촬영한 이미지를 TCP를 통해 서버로 전송</br>
└─ 서버로부터 세션 코드 수신 및 표출</br>
</br>

### 네트워크
├─ 통신 방식: TCP</br>
└─ 라이브러리: Telepathy (Unity용 TCP 통신 라이브러리)</br>
이미지 데이터는 이진 형태로 서버에 전송되며 세션 코드와 함께 관리되어 다른 클라이언트로 전달됩니다.</br>
